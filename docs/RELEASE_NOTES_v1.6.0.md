# X Archive Gallery v1.6.0 更新内容

作成：2026年10月27日 / M.Nesuka  
公開済みv1.5.0からの変更まとめ。ローカル最終版候補を準備済みで、GitHubへの公開はまだ行っていません。

## 利用者向けの主な変更

### 1. 最初の取り込みを分かりやすく
- 広いメイン画面で、保存先を選ぶ → ZIPを選ぶ → 取り込み開始へ進めます。
- Analyticsは任意。ZIPとCSVをまとめて取り込むことも、後からCSVだけ追加することもできます。
- 操作途中からの再開、保存先を選び直す導線、低解像度・高DPIでの配置を改善しました。
- 使い方を項目ごとに整理し、更新方法を具体例で説明しています。

### 2. タグ管理を整理
- タグをグループに分け、グループ名の下にタグを並べるツリー表示を追加しました。
- 複数タグを選んで、まとめてグループ移動・削除・色変更できます。色はクリックですぐ反映します。
- タグ名・グループ・色と、自動タグの設定を分けました。新規作成中に別のタグの色が変わる問題も修正しました。
- 赤・黒・白・金を追加し、タグ色は合計34色です。銀は以前からある色です。

### 3. 投稿文からタグを付ける
- 「登録タグ：動物」「検索する言葉：ねこ,いぬ」のように表へ入力できます。登録した言葉は1投稿だけでも対象です。
- 本文とハッシュタグを照合し、過去に取り込んだ作品にも反映できます。
- 別の選択肢として「よく使うハッシュタグを自動登録」を追加。ONにしたときだけ、初期条件20投稿以上・最大50種類で新しいタグを登録します。
- 複数画像の投稿も1投稿として数えます。投稿数・種類数は最初のセットアップ画面、または自動タグ設定の「基本」で変更できます。保存済みの本文を使うので通常はZIP再読込不要です。
- 上限に達した場合は案内を表示します。必ず使いたいタグを登録タグ・検索語に指定すれば、1投稿から上限外で反映できます。
- 自動登録は初期OFF。登録済みだけを使いたい人の設定を勝手に変えません。
- 削除・除外したタグを復活させず、作品ごとに外したタグも維持します。旧版から残したタグが更新後の投稿へ付かない問題も修正しました。
- 見えない異体字指定文字による、重複や除外漏れを防ぎます。

### 4. アーカイブ更新と設定の引き継ぎを安定化
- 同じ投稿・添付の重複表示を防ぎ、新しい投稿は追加します。同じ画像を別の投稿で使った場合は投稿との対応を保持します。
- 保存先を移動した後に、新しいZIPを選んでも進まない問題を修正しました。
- 同じ実体のフォルダーを別パスから開いた際、タグやAnalyticsが別設定になる問題を修正しました。バックアップ後に設定を統合し、別の実体のライブラリは混ぜません。
- タグ・グループ・お気に入り・非表示などの設定を保持して追加更新できます。

### 5. Analyticsの総合判定と説明を改善
**全体の順位は更新されますが、今回のCSVにない過去作品の数値は以前に取り込んだままです。**

過去分と今回分の保存済みAnalyticsを合わせ、同じライブラリのギャラリーに作品がある投稿全体で、高成績・NO.1を再判定します。検索や年月の絞り込みで順位は変わりません。ギャラリーに作品のない投稿がNO.1を奪う問題を修正しました。

例：過去作品Aが保存済みの数値で100いいね、新作Bが今回のCSVで200いいねなら、いいね数ではBがAを上回ります。AがX上で150いいねに増えていても、今回のCSVにAがなければ100のまま比較します。Aの数値も更新したければ、その投稿を含む期間の新しいCSVを追加してください。いいね率などはそれぞれの指標で比較します。

- 直近1か月だけのランキングにはなりません。ただし全期間の数値が最新になるわけではありません。
- Analyticsを一度も取り込んでいない作品は、数値が不明なため判定できません。
- 元CSVのバックアップ保存は新規設定で初期ON。既存の明示的なOFF選択は保持します。
- バックアップCSVは復旧用です。古いCSVの再読込で最新数値が取得できるわけではありません。
- Windowsの長い保存先でもCSV原本を安全に保存できるよう改善しました。

### 6. 無駄な処理を削減
- 投稿文や設定が変わっていなければ自動タグの照合結果を再利用します。
- 大量の照合は背景で処理し、色変更だけで一覧全体を作り直す処理や、同色を指定したときのDB書き込みを減らしました。
- 大きな画像の読み込み待ちを制限し、50MiBを超えるCSVを全読み込み前に拒否します。
- 仮想描画、サムネイル・表示キャッシュの上限、最小化時の省電力を維持しています。
- これはすべてのPCやデータ量で同じ高速化率を保証する説明ではありません。

## 以前からある機能
日本語・English、ダーク・ライト、複数アカウント、手動タグ・お気に入り、極小表示、スライドショー、画像・GIF・動画、任意Analytics、CSV原本保存、累積成績、重複非表示、省電力、単一EXE、Source Availableはv1.5.0から利用できる機能です。今回すべてを新規追加したわけではありません。

## v1.5.0からの更新方法
1. 使用中のアプリを閉じます。
2. v1.6.0のWindows ZIPを展開し、その中のXArchiveGallery.exeを開きます。以前と同じWindowsユーザーで使ってください。
3. 作品が自動で開かない場合は「保存済みの作品を開く」から今までの作品フォルダーを選びます。初期化は不要です。
4. DBは整合性確認・更新前バックアップ・安全な処理を経てschema8から9へ更新します。作品・タグ・お気に入り・Analytics等を保持します。

旧版へ戻す場合、新しいDBを古いEXEで直接開かず、アプリを終了し、現在のDBを保管したうえで更新前DBを復元してください。作品フォルダーを削除する必要はありません。

## English summary
v1.6.0 adds tag groups, bulk tag editing, table-based post-text rules, optional frequent hashtag registration (initially 20 posts / 50 types), and four tag colors. It improves onboarding, archive updates, library identity recovery, CSV backup and background processing. Existing language, theme, account, slideshow and Analytics features remain available.

Overall rankings are recalculated across gallery artwork posts with saved Analytics. Older works absent from the new CSV keep their previous numbers; a recent-month CSV does not make every work’s metrics current. Original CSV backups help recovery, not live updates. The release has been prepared locally and has not been published to GitHub.
